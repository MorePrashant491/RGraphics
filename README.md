# RGraphics — Phase 1

Full-stack foundation for the RGraphics printing and graphic-design e-commerce platform.

## Stack
- Frontend: React + Vite
- Styling: Tailwind CSS v4
- Backend: Node.js + Express
- Database: MongoDB
- Authentication-ready: JWT
- Design editor-ready: Fabric.js
- Icons: Lucide React
- API: REST

## Run

### Backend
```bash
cd server
npm install
npm run dev
```

### Frontend
```bash
cd client
npm install
npm run dev
```

Backend defaults to http://localhost:5000
Frontend defaults to http://localhost:5173

Create `server/.env` from `.env.example` before connecting MongoDB.
